《轻舟解压》隐私政策与使用条款

更新日期：2026-10-13

一、我们处理的信息

1. 文件数据：你在本应用中进行的压缩包预览、解压等操作，全部在你的手机本地完成，我们不会上传你的任何文件内容。

2. 设备与日志信息：当前版本不收集、不上传任何设备信息与运行日志。

3. 本应用不注册账号、不登录，不收集你的姓名、手机号、身份证号等个人身份信息。

二、权限使用说明

1. 存储 / 所有文件访问权限：用于浏览压缩包、读取压缩包内容、保存解压结果。这是本应用核心功能所必需的权限，仅在完成上述操作所必需的范围内使用；本应用不会读取或上传与上述功能无关的任何数据。

2. 通知权限：用于在通知栏展示解压进度与完成结果。你可随时在系统设置中关闭，关闭后不影响解压功能本身。

3. 前台服务权限：用于在应用退到后台时继续执行解压 / 压缩任务，避免处理大文件时被系统中止。

4. 网络权限：用于后续版本加载广告。当前版本不会使用该权限上传你的任何数据。

5. 震动权限：用于点击时的触感反馈，可在「我的 → 交互」中关闭。

本应用不申请通讯录、短信、通话记录、位置、相机、麦克风等任何与解压功能无关的权限。

三、第三方 SDK 清单

当前版本未接入任何第三方广告 SDK、数据统计 SDK 或其他数据收集组件。本应用的全部功能（含压缩包预览、解压、加密包处理）均在手机本地完成，不向任何服务器发送数据。

若未来版本接入广告或其他第三方 SDK，我们会在本页完整列明 SDK 名称、运营方、收集的信息类型、使用目的与隐私政策链接，并在应用内提前告知。

四、广告与个性化推荐

当前版本不含任何广告。

未来若接入广告，你可以在应用内「我的 → 隐私」中关闭「个性化广告推荐」；关闭后仍会展示广告，但仅展示与你的兴趣无关的通用广告。

五、信息的共享、转让与公开披露

我们不会向任何第三方出售或共享你的个人信息。当前版本不存在任何数据对外共享场景。

六、你的权利

你有权查阅、更正、删除你的个人信息，并有权撤回此前作出的同意。由于本应用不收集个人身份信息且所有文件处理均在本地完成，你可通过卸载应用彻底清除本地数据。

七、未成年人保护

若你是未满 14 周岁的未成年人，请在监护人陪同下阅读本政策并使用本应用。

八、政策更新

本政策如有更新，我们会在应用内及本页面提示；继续使用本应用即视为接受更新后的政策。

九、联系方式

如对本政策有任何疑问，可通过邮箱与我们联系： chuliuqixiuerban@foxmail.com； 也可在应用内「我的 → 意见反馈」中提交。

十、其他

若你不同意本政策，请点击「不同意并退出」，我们不会收集任何信息，但无法为你提供服务。
